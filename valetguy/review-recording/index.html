App Review 錄影腳本（逐步）

Apple Guideline 2.1 要求：實機、最新 iOS、從點 App 圖示開始，錄到一般使用流程，以及登入、建立帳號、刪除帳號、訂閱畫面（方案名稱、期間、價格、使用條款與隱私權政策連結）。錄好的影片附在 App Review 的回覆裡（Notes 第 1 題）。

  • 帳號：錄影帳號（錄影專用，用 Email 驗證碼登入；錄完在 App 裡刪除帳號）。
  • 驗證碼收件匣：（見內部文件）
  • 版本：從 TestFlight 安裝送審的 build（目前 Build 6）。
  • 長度：約 5–7 分鐘，不用剪輯；中間停頓沒關係。按鈕名稱是英文介面（括號是中文）。

錄影前準備（不用錄）

  1. App 語言設成英文：iPhone 設定 › App › ValetGuy › 語言 › English（審查員看英文）。
  2. 螢幕錄製：設定 › 控制中心 › 加入「螢幕錄製」。麥克風關閉。
  3. 勿擾模式打開，避免通知跳出來。
  4. 確認 錄影帳號 目前不屬於任何組織（第一次用就是）。
  5. Safari 先開好 收件匣分頁（上面的網址），方便切過去拿驗證碼。
  6. ValetGuy 如果已登入別的帳號，先登出（左上角名稱 › Settings › Sign out），回到登入畫面。然後把 App 從背景關掉，讓錄影從啟動開始。
  7. 手邊準備一台車（或任何物體）讓收車時拍照；車牌可以手動輸入假的，例如 7ABC123。

開始錄影

從控制中心開始錄影，回到主畫面。

1. 啟動與登入

  1. 點主畫面的 ValetGuy 圖示。
  2. 在 Work email 輸入 錄影帳號 → Send code（寄送驗證碼）。
  3. 切到 Safari 的 收件匣分頁 → 重新整理 → 打開最新一封 → 看驗證碼。
  4. 切回 ValetGuy → 輸入驗證碼 → 登入。

2. 建立組織（新帳號的第一步）

  1. 點 Create organization（建立組織）。
  2. Organization name：Demo Valet Co.；Region：United States；時區用預設；Site name：Main Entrance；Your name：Alex。
  3. 按 Create organization。進到看板（空的）。新組織自動有 7 天專業版試用，第 8 步的方案頁會看到。

3. 收車（Check In 分頁）

  1. 點下方 Check In（收車）→ Start check-in（開始收車）。
  2. Plate：輸入 7ABC123（或掃描車牌）→ Next（下一步）。
  3. Make：選 Toyota，Model 可填 RAV4 → Next。
  4. Color：選 White → Next。
  5. Mileage：油量點 ¾ → Next。
  6. Photos：拍車頭、車尾、左側、右側（拍不到可以只拍兩張，按 Continue anyway（仍要繼續））。
  7. Owner：電話可以不填 → Issue ticket（開立泊車單）。
  8. 畫面出現泊車單號和 QR Code。點 Share link（分享連結）→ Copy（拷貝）。
    • 停 2 秒，讓 QR Code 和單號看得清楚。

4. 車主網頁叫車（Safari）

  1. 切到 Safari → 新分頁 → 貼上連結 → 前往。
  2. 車主頁面出現「Is this your car?」→ 點 This is my car — link this phone。
  3. 頁面顯示車輛狀態和 4 位數取車碼（Pickup code）。記下這個號碼（交車要用）。
  4. 先不要按叫車，切回 ValetGuy。

5. 停車（看板）

  1. 點下方 Board（看板）。車在「Checking in」欄。
  2. 卡片上按 Start parking（開始停車）。
  3. 再按 Mark parked（標記已停妥）→ Parking spot 點一個車位（例如 P1）→ Where is the key? 點一個掛位（例如 1）→ Confirm parked（確認已停妥）。

6. 車主叫車

  1. 切到 Safari 的車主頁面 → 點 Request my car（我要取車）→ 確認。
  2. 頁面變成「已叫車」並開始計時。切回 ValetGuy。

7. 取車與交車

  1. 看板的車移到「Requested」（叫車中）欄。按 Assign attendant（指派取車人員）→ 選自己（Alex）。
  2. 按 Start retrieval（開始取車）→ 跳出鑰匙提示時選取下鑰匙。
  3. 按 Car ready（車已備妥）→ 選 In the car（在車內）→ Car ready。
  4. 車在「Ready」（交車中）欄 → 按 Deliver（交車）→ 提示「The key is in the car」→ Continue。
  5. Confirm delivery（確認交車）頁：輸入第 4 步記下的 取車碼 → 顯示相符 → 右上角 Deliver。
  6. 切到 Safari 看一下車主頁面變成「已交車」（可略過）→ 切回 ValetGuy。

8. 設定與訂閱畫面

  1. 點左上角名稱（Alex · Main Entrance）→ Settings（設定）。
  2. 往下捲，讓 Organization 區塊看得到：Plan、Invite a staff member、Staff、Attendance records、Work sites、Backups。
  3. 點 Plan（方案）→ 往下捲到 Subscribe（訂閱）區塊，停 3 秒，讓下列都看得到：
    • 兩個方案的名稱、每月、價格（Basic US$29.99 / month、Pro US$79.99 / month）。
    • 自動續訂說明、Terms of Use 和 Privacy Policy 連結。
  4. 點 Pro 的購買 → 跳出 Apple 的沙盒付款視窗 → 確認購買（TestFlight 版不會扣款）→ 回到方案頁，顯示已訂閱。
    • 可以點 Terms of Use 打開一下再返回（選擇性）。
  5. 返回設定。

9. 刪除帳號（必錄）

  1. 設定最下面 → Delete account（刪除帳號）。
  2. 輸入組織名稱 Demo Valet Co. → 確認刪除。
  3. App 回到登入畫面。

停止錄影（控制中心）。

錄完之後

  • 影片在「照片」App。確認：從主畫面點圖示開始、看得到登入、建立組織、訂閱畫面的價格與條款連結、刪除帳號。
  • 刪除帳號後，錄影帳號 的組織和資料都刪除了；沙盒訂閱會自然到期，不用處理。
  • 送審時：App Store Connect › App Review 回覆（或 App Review Information 的附件）上傳影片；Notes 第 1 題已描述影片內容（review-notes.md）。
  • 需要重錄：同一個 Email 可以再登入，會是全新帳號（要再建立組織）。

常見狀況

  • 收不到驗證碼：收件匣重新整理；或按 App 裡的「重新寄送」。驗證碼是最新那封。
  • 車主頁面打不開：確認是 TestFlight 版，而且有網路；連結是 https://valet.goodsvalu.com/t/#…。
  • 取車碼對不上：確認是同一張單的車主頁面；在第 4 步按過「This is my car — link this phone」才會顯示取車碼。
  • 沙盒付款視窗要求登入：用 iPhone 設定 › App Store › 沙盒帳號（或 TestFlight 會用你的 Apple ID 免費測試）。
