關於 Goodsvalu

我們是一支軟體開發團隊，一邊做自己的產品，一邊幫企業開發專屬的系統。

我們在做的事

我們相信軟體應該讓事情變簡單：少一個步驟、少一張紙、少一次重複輸入。

我們的工作分兩部分：開發自有的軟體產品，以及為有特定需求的企業打造專屬的應用程式。

範圍包含手機與桌面應用程式、網站系統，以及結合 AI 的工具。

使命

讓軟體更實用、更容易取得。

開發能簡化日常工作、幫企業運作得更順的軟體，把真實的問題變成好用的工具。

願景

每個人都用得到簡單好用的軟體。

不論是個人還是中小企業，都能用到簡單、有效率，而且能隨需求調整的軟體。

我們的做法

  1. 1了解問題

    先釐清軟體要解決的問題、目標與實際限制。

  2. 2設計

    畫面與流程以清楚、好用為優先。

  3. 3開發

    選擇適合這個專案的技術，寫出穩定、好維護的程式。

  4. 4持續改進

    依使用者回饋更新，維護是產品的一部分。

自有產品與客製開發

Goodsvalu 同時做兩件事：為一般使用者開發軟體產品，以及為企業的特定需求開發客製系統。

自己開發、上架並營運產品，讓我們在接案時更重視實用的功能、順暢的流程，以及上線後的維護。

  • CalendarScan把紙本行程變成行事曆事件
  • ValetGuy代客泊車的營運系統
  • Siaupoa拍收據或說一句話就能記帳
  • PassNest完全離線的密碼管理器

開發原則

好的軟體不需要複雜，也不應該拿使用者的資料交換便利。

簡單
每個畫面只做一件事，讓使用者不需要說明書。
隱私
能留在裝置上的資料，就不上傳。
由人確認
AI 負責找出資訊，最後的決定交給使用者。
好維護
寫給未來的自己看得懂的程式碼與文件。

About Goodsvalu

We’re a software development team. We make our own products, and we build custom systems for businesses.

What we do

We think software should make things simpler: one step fewer, one less piece of paper, no typing the same thing twice.

Our work has two parts: building our own software products, and building tailored applications for businesses with specific needs.

That covers mobile and desktop apps, web systems and tools with AI features.

Mission

Make software more practical and easier to get.

Build software that simplifies daily work and helps businesses run more smoothly, turning real problems into useful tools.

Vision

Simple, useful software for everyone.

Individuals and small businesses alike should have software that is simple, efficient and able to change with their needs.

How we work

  1. 1Understand the problem

    First we pin down the problem, the goal and the real constraints.

  2. 2Design

    Screens and flows put clarity and ease of use first.

  3. 3Build

    We pick technology that suits the project and write stable, maintainable code.

  4. 4Improve

    We update based on user feedback; maintenance is part of the product.

Products and client work

Goodsvalu does two things at once: software products for everyday users, and custom systems for specific business needs.

Building, releasing and running our own products keeps our client work focused on useful features, smooth workflows and life after launch.

  • CalendarScanTurns paper schedules into calendar events
  • ValetGuyRuns a valet parking operation
  • SiaupoaBookkeeping from a receipt photo or one sentence
  • PassNestA password manager that never goes online

Principles

Good software doesn’t need to be complicated, and shouldn’t trade your data for convenience.

Simple
Each screen does one thing, so no manual is needed.
Private
If data can stay on the device, it does.
A person confirms
AI finds the information; people make the final call.
Maintainable
Code and docs our future selves can understand.
